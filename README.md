Пишу сайты и веб-приложения на Laravel. Мобильные приложения делаю на React Native и Expo. Ещё пишу плагины и моды для Minecraft и делаю игры на Godot.

Ищу удалённую работу junior-разработчиком или стажировку.

## Проекты

### [EDO Portal](https://github.com/SemGAA/edo-portal)
Сервис для работы с документами. Можно создать документ, отправить на согласование, вернуть на доработку или убрать в архив. Есть доступ по ролям и отделам, история действий и поиск.

`PHP` `Laravel` `Livewire` `SQL`

[Код и запуск](https://github.com/SemGAA/edo-portal#readme)

### [Cinema Notes](https://github.com/SemGAA/Program_kinp)
Приложение для Android с поиском фильмов, сериалов и аниме, комнатами просмотра, друзьями и заметками. Код приложения и Laravel API лежит в одном репозитории.

`TypeScript` `React Native` `Expo` `Laravel API`

[Страница проекта](https://semgaa.github.io/Program_kinp/) | [Скачать APK](https://github.com/SemGAA/Program_kinp/releases) | [Код](https://github.com/SemGAA/Program_kinp)

### [Minecraft Meteor Mod](https://github.com/SemGAA/minecraft-meteor-mod)
Добавляет падение метеорита в Minecraft 1.21. Событие обрабатывается на сервере, эффекты отображаются на клиенте.

`Java 21` `Forge` `Gradle`

[Скачать мод](https://github.com/SemGAA/minecraft-meteor-mod/releases) | [Код](https://github.com/SemGAA/minecraft-meteor-mod)
