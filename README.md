## Проекты

### [EDO Portal](https://github.com/SemGAA/edo-portal)
Электронный документооборот: создание документов, согласование, возврат на доработку и архив. Доступ по ролям и отделам, история действий, поиск и фильтры.

`PHP` `Laravel` `Livewire` `SQL`

[Код и запуск →](https://github.com/SemGAA/edo-portal#readme)

### [Cinema Notes](https://github.com/SemGAA/Program_kinp)
Android-приложение для фильмов, сериалов и аниме: поиск, комнаты просмотра, друзья и заметки. В репозитории — приложение и серверная часть, в релизах — APK.

`TypeScript` `React Native` `Expo` `Laravel API`

[Страница проекта →](https://semgaa.github.io/Program_kinp/) · [Скачать APK →](https://github.com/SemGAA/Program_kinp/releases) · [Код →](https://github.com/SemGAA/Program_kinp)

### [Minecraft Meteor Mod](https://github.com/SemGAA/minecraft-meteor-mod)
Мод для Minecraft 1.21: падение метеорита, серверная логика события и визуальные эффекты на клиенте.

`Java 21` `Forge` `Gradle`

[Скачать мод →](https://github.com/SemGAA/minecraft-meteor-mod/releases) · [Код →](https://github.com/SemGAA/minecraft-meteor-mod)
